# Logic Study Course

This course turns the ideas in *Introduction to Logic* into small, ordered lessons that are easier to understand and practice.

## Learning structure

**教材章节**:
One of the book's 14 numbered chapters, used to preserve the source's overall learning order.

**课次**:
A learning unit mapped one-to-one to one numbered section in the book. This project has 90 numbered lesson units.
_Avoid_: 小节页

**自测题**:
An original practice question that checks one lesson's core idea and includes an explanation of the answer.
