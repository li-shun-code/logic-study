# 1.4 论证与说明

> **这节课解决什么困惑**：同样一句"因为……所以……"，为什么有时是在证明一个结论，有时只是在解释原因？

## 学习目标与先修概念

- **学完这课你能**：用"结论的真假是否已经确定"这条标准，把论证和说明分开；判断一段模糊的话该按哪种来读。
- **先修概念**：1.2 的命题、1.3 的前提与结论。

## 一句话，两种用途

"因为"和"所以"既能引出论证，也能引出说明。区别不在词，而在**说话人的意图**。

《马太福音》里劝人"积攒财宝"，后面给出理由——这是在论证：结论是"你应当积攒财宝"，理由用来让你接受这个主张。而《创世记》讲巴别塔，说人类傲慢建塔，上帝变乱语言，"巴别"就是"混淆"的意思——这里不是在证明"巴别塔发生过"，而是在解释"为什么叫巴别"。一个是论证，一个是说明。

## 判断标准：那个结论已经确定了吗

一句简单好用的规则：

> 看结论（Q）的真假是不是还有待确立。
> - 如果 Q 还待确立，给出理由是为了让你接受 Q——这是**论证**。
> - 如果 Q 已知为真，给出理由是为了解释 Q 为什么成立——这是**说明**。

比如天文学里，类星体发出很强的红外辐射。如果有人还在争论"类星体到底是不是真的发出红外"，拿理由来支持这个说法，那是论证；如果大家已经确认它发出红外，再解释"因为太空中的氢微粒吸收了蓝光、剩下的红外被我们看到"，那就是说明。

## 模糊地带要看语境

有些例子两边都讲得通。比如水的独特性质——水凉的时候密度反而减小，最冷的一层浮到上面，所以湖泊从上往下结冰。这段可以是在论证"水有这种反常性质"，也可以是在已知性质后解释"为什么湖面先结冰"。到底是哪一种，得看上下文里作者想解决什么。

《牛津英语词典》追溯一个词的来历，也是说明：它默认这个词现在的意思已经确定，只是解释它怎么来的。同一个事实，可以给出好几种不同的说明——哪种更贴切，是另一回事。

## 常见误解

- **"有'因为'就是论证"**：不对。说明里也满是"因为"，比如"因为氢微粒吸收蓝光，所以看到红外"。
- **"说明比论证低级"**：不是。说明回答"为什么"，论证回答"凭什么信"，是两种不同的理智任务。
- **"一段话只能是一种"**：同一段话在不同语境下可以换角色；判断靠意图和已知状态，不靠固定词。

## 自测题（据原书第 1.4 节练习）

1. 《马太福音》"积攒财宝"和《创世记》"巴别塔"，哪一个是论证，哪一个是说明？为什么？
2. 类星体的红外辐射：如果结论还没被接受，给出理由是论证还是说明？如果已被接受呢？
3. 水在凉的时候密度减小、最冷层上浮——为什么这段话既可能读作论证，也可能读作说明？

<details>
<summary>展开答案</summary>

1. "积攒财宝"是论证：它在用理由让你接受一个应当做的事。"巴别塔"是说明：它默认巴别塔和名字的来源已知，只是在解释"巴别"为什么是"混淆"的意思。
2. 待测真假时是论证：理由用来确立"类星体发出红外"这个结论。已知为真时是说明：理由用来解释"为什么我们观测到强红外"。
3. 如果作者想让你接受"水有这种反常性质"，那是论证；如果已经承认这个性质、只是解释"湖泊为何从上面开始结冰"，那是说明。角色取决于作者意图和语境。
