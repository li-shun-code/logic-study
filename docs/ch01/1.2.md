# 1.2 什么样的句子能当前提

> **这节课解决什么困惑**：祈使句、疑问句、感叹句都不能当论证的一部分？凭什么？

## 从一句没法反驳的话说起

有人喊："今天真冷啊！"你没法说这句话"错"，因为它没有真假。它是在表达感受，不是在陈述事实。

再看："请把窗户关上。"这也不是真的或假的——它是一个请求。

逻辑学要的建材很挑：**只有能判定真假的句子，才能当论证的前提或结论。**这种句子叫**命题 proposition**。

## 命题 vs 句子

| 句子类型 | 例子 | 有真假吗 | 是命题吗 |
| --- | --- | --- | --- |
| 陈述 | 北京是中国的首都 | 有（真） | 是 |
| 疑问 | 今天下雨吗？ | 无 | 否 |
| 祈使 | 把门关上 | 无 | 否 |
| 感叹 | 好美的花！ | 通常无 | 否 |

注意一个细节：同一个"句子"在不同场合可能表达不同命题。" president is in Washington"（总统在华盛顿）这句话，指的是哪一国的总统、哪个华盛顿，取决于语境。**命题是句子在特定语境下表达的内容**，不是字面本身。

## 简单命题与复合命题

**简单命题**不含有其他命题作为组成部分：

> 苏轼是宋代人。

**复合命题**由逻辑连接词把若干命题组合而成。三种基本连接：

- **合取 conjunction**："并且"。`P 并且 Q`——两个都真才真。
  - 例：苏轼是宋代人，并且李白是唐代人。
- **析取 disjunction**："或者"。`P 或者 Q`——至少一个真就真。
  - 例：今天下雨，或者今天下雪。
- **条件 conditional**："如果……那么"。`如果 P，那么 Q`——叫前件 P、后件 Q。
  - 例：如果天下雨，那么地面会湿。

这里只需要认出这三种结构。第 8 章会用真值表把它们精确化。

## 一个容易掉进去的坑

看这句话：

> 张三和李四去爬山了。

这是简单命题还是复合命题？**简单**。因为"张三"和"李四"是同一个动作的共同主语，并没有把"张三去爬山"和"李四去爬山"两个命题用"并且"连接——虽然可以改写成一个合取命题，但原句本身是一个整体陈述。

对比：

> 张三去爬山了，并且李四去爬山了。

这才是复合命题。区分的关键：**连接词连接的是两个完整命题，还是只是一个句子的成分。**

## 为什么必须先认出命题

后面所有工具——论证图、三段论、真值表——都只操作命题。如果你把一句感叹或请求当成前提塞进去，整个分析会从根上错掉。

养成一个习惯：**分析论证前，先把每段话里哪些是命题圈出来。**

## 自测题

1. 下列句子哪些是命题？
   - (a) 2 + 3 = 5
   - (b) 请保持安静
   - (c) 火星上有生命
   - (d) 哎哟，好痛！
2. 判断下列命题是简单还是复合，若是复合指出连接词类型：
   - (a) 她喜欢音乐和绘画
   - (b) 她喜欢音乐，并且她会弹琴
   - (c) 如果明天下雨，运动会就延期

<details>
<summary>展开答案</summary>

1. (a) 是（真命题）；(b) 否（祈使）；(c) 是（虽然我们还不知道真假，但它有真假）；(d) 否（感叹）。
   - 关键点：命题不要求我们**知道**它的真假，只要求它**有**真假。"火星上有生命"是命题。
2. (a) 简单命题——"音乐和绘画"是喜欢的对象，不是一个合取命题。(b) 复合命题，合取。(c) 复合命题，条件命题。
</details>
