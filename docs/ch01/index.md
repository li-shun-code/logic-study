## 本章回顾

把六课连成一条线：逻辑学研究的是区分正确推理和不正确推理的方法。它的基本单位是论证——一组命题，结论由前提支持。前提和结论都得是命题：断定事实、有真假的句子；问句、命令、感叹都不算。

现实中的论证不像教科书那么整齐，要靠指示词和语境把它辨识出来；反问句和省略的前提都要先摆成命题。同一段话还可能是说明而不是论证，区别在于结论的真假是否已经确定。

最后两课给出评判标准：演绎声称前提必然推出结论，这种连接叫有效；归纳只声称或然支持，评的是强弱。真（命题的性质）、有效（演绎论证的性质）、可靠（有效且前提真）三个词分工不同，不能混。

## 关键术语

| 术语 | 英文 | 一句话 |
| --- | --- | --- |
| 命题 | proposition | 断定事实、有真假的句子 |
| 简单命题 | simple proposition | 不含其他命题作为成分 |
| 复合命题 | compound proposition | 由连接词把若干命题拼成 |
| 论证 | argument | 结论被声称由前提支持的一组命题 |
| 前提 / 结论 | premise / conclusion | 支持者 / 被支持者 |
| 演绎 | deduction | 声称前提对结论提供决定性支持 |
| 归纳 | induction | 声称前提对结论提供非决定性支持 |
| 有效 | valid | 演绎论证的性质：前提真则结论不可能假 |
| 可靠 | sound | 有效且所有前提真的论证 |
