## 本章回顾

读到这里，把六课连成一条线：逻辑学研究的不是"大家通常怎么想"，而是"怎样分辨一个推理靠不靠得住"。起点是命题——只有有真假的句子才有资格当前提和结论。前提和结论合在一起才是论证；论证要靠指示词和语境去找，而不是靠"我觉得这句像结论"。同一个"因为"可能是论证（给理由让人相信），也可能是说明（解释为什么），区别在作者意图。

最后两课把评价标准讲清楚：演绎论证声称前提"必然"推出结论，这种关系叫有效；归纳论证只声称"大概率"支持，没有有效无效，只有强弱。还要把真（命题的性质）、有效（演绎论证的性质）、可靠（有效且前提真）分开——这是初学者最容易混的三个词。

## 关键术语

| 术语 | 英文 | 一句话 |
| --- | --- | --- |
| 命题 | proposition | 有真假值的陈述句，是推理的砖块 |
| 简单命题 | simple proposition | 不含其他命题作为成分的命题 |
| 复合命题 | compound proposition | 由连接词把若干命题组合而成 |
| 论证 | argument | 由前提推出结论的一组命题 |
| 前提 / 结论 | premise / conclusion | 支持者 / 被支持者 |
| 演绎 | deduction | 声称前提对结论提供必然支持 |
| 归纳 | induction | 声称前提对结论提供或然支持 |
| 有效 | valid | 演绎论证的性质：前提真则结论不可能假 |
| 可靠 | sound | 有效且前提都真的论证 |
