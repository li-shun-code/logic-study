> 本章共 6 课。我们从语言在干什么说起，一路走到定义怎么搭，因为推理所用的每一句话，都先在语言里成形。

## 本章回顾

3.1 到 3.3 处理的是语言本身。语言不只传递信息，还能表达情感、指挥行动、完成仪式和做出承诺；语词既有描述层面的意思，又有情感层面的分量，广告、政治和委婉语都在利用这一点。面对一场争论，先别急着站队，看它是不是由词义含混引起的：能靠澄清消除的，是言辞之争；澄清之后还在的，是实质分歧。

3.4 到 3.6 处理的是定义。定义的对象始终是符号而不是东西本身，用途不同，真假标准也不同。往下拆，词项的意义有外延和内涵两层：外延是它适用的对象，内涵是判断的标准；内涵决定外延，反过来不行。最常用的内涵定义办法是属加种差——挑一个属，再找种差，同时避开循环、过宽过窄、晦涩比喻和不必要的否定。

## 关键术语

| 术语 | 英文 | 一句话 |
| --- | --- | --- |
| 信息性语言 | informational language | 用来传递事实与信息的语言。 |
| 表达性语言 | expressive language | 用来表达说话者情感或态度的语言。 |
| 指令性语言 | directive language | 用来影响或指导他人行为的语言。 |
| 仪式性语言 | ceremonial language | 用于社交场合、完成礼仪的语言，如问候。 |
| 述行性语言 | performative language | 说出来就等于做了那件事的语言，如道歉、祝贺、答应。 |
| 中性语言 | neutral language | 以传递信息为主、情感色彩较弱的语言。 |
| 委婉语 | euphemism | 用较温和的说法替换直白或刺耳的说法。 |
| 歧义 | ambiguity | 一个词项有多个意思，语境中分不清用的是哪个。 |
| 模糊 | vagueness | 存在临界状况，无法确定词项适不适用。 |
| 实质争论 | genuine dispute | 信念或态度上的真实分歧，澄清词义也消不掉。 |
| 言辞之争 | verbal dispute | 分歧仅由词义含混造成，澄清后即消失。 |
| 被定义项 | definiendum | 被定义的那个符号。 |
| 定义项 | definiens | 用来说明被定义项的另一串符号。 |
| 规定定义 | stipulative definition | 规定某个符号从今往后指什么，无真假。 |
| 词典定义 | lexical definition | 报告一个词已有的用法，有真假。 |
| 精确定义 | precising definition | 通过划清界限消除歧义或模糊。 |
| 理论定义 | theoretical definition | 概括一套理论的定义。 |
| 说服定义 | persuasive definition | 借定义暗塞情感、操纵态度。 |
| 普遍词项 | general term | 可以适用于一个以上对象的词项。 |
| 外延 | extension | 词项正确适用的全部对象构成的集合。 |
| 内涵 | intension | 决定某对象是否属于该词项外延的标准。 |
| 指称性定义 | referential definition | 通过指出词项的外延来定义。 |
| 实指定义 | ostensive definition | 指着对象并说出被定义词来定义。 |
| 同义定义 | synonymous definition | 用一个已知的同义词来解释词项。 |
| 操作定义 | operational definition | 用可执行、可重复的操作来定义词项。 |
| 属加种差定义 | definition per genus et differentia | 用"所属的类 + 区别于其他种的独特属性"来定义。 |
