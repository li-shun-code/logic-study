## 本章回顾

这一章要拿走的是一个区分和一个工具。区分是：争论看起来在吵事实，其实常常在吵词——3.3 把它拆成实质争论（事实或价值真有分歧）、纯粹语词争论（换定义就消失）、看似语词实则实质的争论（定义背后藏着真分歧）。含混性和定义就是制造这类混乱的源头：3.1 说明一句话可以同时传递信息、表达情绪、发出指令；3.2 说明情绪词和委婉语会替你把判断塞进描述里。

工具是定义：3.4 讲定义的对象是符号而不是实物，以及规定、词典、精确化、理论、说服五种用途；3.5 讲外延（词适用的东西）和内涵（词暗示的属性）是两层不同的含义；3.6 的属加种差加五条规则，给你一个写出清楚定义的检查表。下次遇到吵不清的争论，先问：这是事实、态度，还是定义问题？

## 关键术语

| 术语 | 英文 | 一句话 |
| --- | --- | --- |
| 信息性功能 | informational function | 语言用来传递事实信息 |
| 表达性功能 | expressive function | 语言用来表达情绪或态度 |
| 指令性功能 | directive function | 语言用来影响他人行为 |
| 情感语言 | emotive language | 带情绪色彩、会影响态度的词语 |
| 委婉语 | euphemism | 用温和说法替换刺耳事实的表达 |
| 实质争论 | substantive dispute | 关于事实或价值的真实分歧 |
| 语词争论 | verbal dispute | 仅因词语定义不同而起的争论 |
| 定义 | definition | 说明一个符号的意义 |
| 规定定义 | stipulative definition | 为某个词特意指定一个用法 |
| 词典定义 | dictionary definition | 记录词语的通常用法 |
| 精确化定义 | precisifying definition | 把模糊词语变得精确 |
| 理论定义 | theoretical definition | 在理论框架中确定词语含义 |
| 说服定义 | persuasive definition | 借定义改变人对某事物的态度 |
| 外延 | extension | 一个词实际适用的所有对象 |
| 内涵 | intension | 一个词所暗示的属性集合 |
| 属加种差 | genus and difference | 用邻近的属加上区别性特征来定义 |
