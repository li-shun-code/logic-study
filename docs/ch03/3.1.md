# 3.1 语言的功能

> **这节课解决什么困惑**：同一句话，为什么有时是在报告事实，有时是在发泄情绪，有时是在指挥别人做事？看见感叹号就一定是感叹，看见问号就一定在提问吗？

## 学习目标与先修概念

- **学完这课你能**：说出语言的三种主要功能，再认出两种不太常见的用法；判断一句话的真实功能时先看语境，而不是先看句子的语法形式；看懂为什么一句话可以同时干好几件事。
- **先修概念**：1.2 的"命题"——只有断定事情、有真假的句子，才能充当论证的前提和结论。逻辑学家最关心语言的信息性用法，正是因为论证要用命题。

## 语言不只干一件事

我们用语言推理，主要是用它处理带信息的话。但语言能做很多事，传递信息只是其中一部分。

有时候我们说"真棒"，并没有报告任何事实，只是把心里的高兴喊出来。一位被古城之美折服的诗人写下"令我震惊的唯有东方大地，/玫瑰红城见证了整个历史"，重点也不是提供旅游资讯，而是抒发胸臆。

有些话则是在指挥。"请站到秤上去"是要你做一件事；"小心驾驶，墓地里到处都是曾经有通行权的守法公民"，表面是一句劝告，实际是在命令你慢点开。

很多时候，一句话同时干好几件事。父母对孩子说"这种行为非常恶心"，既表明了态度，又是在引导孩子别再这样做，还可能是在报告一个事实。语言主要有三种功能：**信息性功能**（informative，报告事实）、**表达性功能**（expressive，表达感受态度）、**指令性功能**（directive，引导或命令行为）。

另外还有两种不太常见的用法：**礼节性功能**（ceremonial），比如被人介绍给陌生人时说"你好"，它把表达和其他功能混在一起；**述行性功能**（performative），话一说出来，它宣称的事就办成了——"我为自己的愚蠢言辞道歉""祝贺你……""我接受你的建议……""我答应你……"，说出这些话本身就是在道歉、祝贺、接受、许诺。

在信息模式下，还要分清"句子陈述了什么事实"和"这句话透露了说话者什么情况"。有人说"战争永远是解决国际冲突的错误办法"，这话可能是真的，同时也是他信念的证据；有人说"我强烈反对我们由于道义卷入这场战争"，这句话本身就是关于说话者的陈述（很可能为真），同时又表达了对这场战争的道德判断。拿自己的观点当辩论的开场，并不是欺骗，这只是把判断和关于自己的报道自然地放在一起。

## 形式和功能，不是一回事

句子的语法形式有四种：陈述句、疑问句、祈使句、感叹句。推理中通常用陈述句；表达感情常用感叹句（"太棒了"）；指挥别人常用祈使句（"脱下你的衬衫！"）。**但形式和功能之间没有严格的对应关系。**

反问句完全可以断言一个前提。虔诚的信徒祷告时问"谁能像你一样？"，这是个疑问句，表达的却是宗教信仰；有人谈话时说"你这么说还可能是什么意思？"，怀疑的态度已经明明白白地表达了出来。反过来，一个规规矩矩的陈述句也能起指挥作用：想催同伴快走，你说"很晚了，我们时间不多了"。年轻女士和绅士路过花店，指着橱窗说"多可爱的花啊！"，这个感叹句很可能更多是在暗示"给我买花"，而不只是单纯赞叹。

所以，决定一句话真正功能的，始终是**语境**。语言太松散，用法太多变，不可能给每种语法形式配死一个功能。

## 混合功能与那件夹克

一句话里同时装着信息和情绪，有时会引起真正的冲突。越战期间，一个抗议征兵的年轻人因为穿着印有脏话的夹克，在洛杉矶地区法院被捕，按加州刑法被判"行为冒犯"罪。最高法院最后推翻了定罪：多数法官认为，这个年轻人的表达性功能和他抗议的信息性功能之间存在张力，而后者受宪法第一修正案保护。

法官约翰·哈伦（John Harlan）写道，许多语言表达都具有双重交流功能：它们既传达相当精确的思想，也传达难以言说的情感；语词常常既因认知力量、也因情感力量而被选用。宪法关注的不能只是言辞的认知内容，情感功能可能恰恰是想要传达的信息中更重要的因素；也不能以为可以禁掉某些特殊言辞，却不冒压制思想的危险。

这个案子说明：在特定语境里，一句话的信息功能可能压过它的冒犯性；对语言用法保持敏感，看清它此刻到底在起什么作用，是做好逻辑分析的前提。

## 常见误解

- **"问句就是提问"**：不一定。祷告里的"谁能像你一样？"是在表达信仰，"你这么说还可能是什么意思？"是在表达怀疑。
- **"感叹句只表达感情"**：不一定。"多可爱的花啊！"在花店橱窗前可能是在指示对方买花。
- **"一句话只能有一种功能"**：不对。说"我强烈反对我们由于道义卷入这场战争"，既报告了说话者的立场，又做出了道德判断；混合功能本来就是语言的常态。

## 自测题（据原书第 3.1 节练习 A、B、C）

1. 下列语段主要体现了哪种语言功能？"请在第 6a 行方框内打叉，除非你父母（或其他人）声明确认你是非独立的所得税申报人。"（美国国税局 1040 表说明，2006）
2. 下列语段最可能打算用作哪种功能？"耕作开始时，其他技艺就随之出现。因此农民是人类文明的奠基者。"（丹尼尔·韦伯斯特，1840）
3. 分析这段语段打算断定什么命题："即使提名我，我也不接受；即使选举我，我也不供职。"（威廉·特库姆塞·谢尔曼，1884）

<summary>展开答案</summary>

1. 指令性功能。这是表格填写说明，目的是让你照着做某件事，不是在描述世界，也不是单纯抒发感受。
2. 信息性功能（其中也带论证）。它先陈述"耕作开始后其他技艺随之出现"，再以"因此"推出"农民是人类文明的奠基者"；主要是在断定事实、支持一个结论。
3. 它断定的命题是：谢尔曼拒绝接受提名，也拒绝在当选后任职。这是他向共和党全国代表大会表明的明确立场，属于信息性断定。
