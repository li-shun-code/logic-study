# 3.1 一句话不止一个功能

> **这节课解决什么困惑**：为什么同一句话，有时是在讲事实，有时是在骂人，有时是在下命令？

## 从一件外套说起

越战时期，有人穿写有挑衅口号的夹克上街。这句话在字面上传达了信息（"我反对……"），但同时**表达情绪**、**挑动反应**。它不只是描述，它还在做事。

语言至少有三种功能：

| 功能 | 在做什么 | 例子 |
| --- | --- | --- |
| 信息性 informative | 陈述事实、传达内容 | "今天气温 30 度" |
| 表达性 expressive | 表达说话人的感受或态度 | "这鬼天气真热！" |
| 指令性 directive | 要求听者做某件事 | "把空调打开" |

还有两种边界功能：**仪式性 ceremonial**（如问候"你好"）和**述行性 performative**（说出这句话本身就是做这件事，如"我承诺""我宣布"）。

## 形式不等于功能

疑问句一般是提问，但有时是要求——"你能把盐递过来吗？"形式上是疑问，功能上是指令。

陈述句一般是信息，但"这真是个好主意啊"在反讽时表达的是否定态度。

所以判断语言功能，不能看句子类型，要看**说话人在具体语境里想做什么**。这和我们在 1.3 里区分论证与说明是同一个思路。

## 逻辑学为什么在乎

论证需要的是**信息性**功能：前提和结论都要有真假。如果一段话主要在执行表达性或指令性功能，它里面可能就没有命题，也就无从谈论证。

但表达性和指令性并不"低级"——它们是人类交流的核心。问题在于：**当它们伪装成信息性陈述时**，会让人误把情绪当证据。

## 自测题

说出下面每句话的主要功能，并指出有无功能混用：

1. "这座桥建于 1990 年。"
2. "这座桥丑得没法看。"
3. "请绕道走。"
4. "你能告诉我现在几点吗？"（语境：说话人只是想知道时间）

<details>
<summary>展开答案</summary>

1. 信息性。
2. 表达性（表达审美态度），虽是陈述句形式。
3. 指令性。
4. 信息性（虽然形式是疑问，但功能是在请求信息；若语境是催促则为指令性）。
</details>
