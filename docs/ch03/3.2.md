# 3.2 情感语言、中性语言与论争

> **这节课解决什么困惑**：换个温和的词，事情就变了吗？两个人在吵架，怎么知道他们是在争事实，还是在争态度？

## 学习目标与先修概念

- **学完这课你能**：看出"中立"的词也会带情绪，认出委婉语和带立场的标签；分清争论中的事实分歧、态度分歧，以及两者兼有的情形。
- **先修概念**：3.1 的信息性、表达性、指令性功能——同一句话可以同时报告事实、表达感受、影响别人。

## 中立的词，也会拨动情绪

用来传达信念的词，可能本身是中立而精确的，但还是会影响听者的情绪——可能是偶然的，也可能是故意设计的。就像（莎士比亚说过的）玫瑰不叫玫瑰依然芳香如故，可如果有人递给你一朵花，同时告诉你它通常被叫作"大麻"，你对这朵花的反应就会不一样。

对某些词的负面反应，催生了**委婉语**（euphemism）：用温和的词汇去表达冷峻的现实。"janitors（看门人）"先变成"maintenance workers（守护员）"，又变成"custodians（管理员）"；"waiters（招待）"变成"waitperson（侍者）"，接着又变成"servers（服务员）"。涉及人类生殖和排泄的医学词汇，本来是中立、不带侮辱的，但它们的粗话同义词因为引发的态度，仍让许多人感到不快。美国广播媒体里就有"七个肮脏的字眼"不能使用，因为它们带有明显区别于字面意义的、让人无法接受的情感意义。

带情感色彩的词，在诗歌里很合适，在调查研究里就很不合适。一个调查的答案，毫无疑问依赖于提问所用的词汇。该避开情感语言，还是该依靠它，全看语言在具体场合要达到什么目的：想客观报道事实，浓厚的感情词会削弱客观性；可有些时候，想完全避开情感内容几乎不可能。堕胎道德性的冲突里，反对堕胎的一方自称"支持生命派"，支持堕胎的一方自称"支持选择派"——两边都在给自己贴标签，逻辑上我们追求的是尽量不被情感意义扭曲的语言。

广告业把玩听众的情感当成核心技巧；政治宣传里修辞也很常见，选哪个词至关重要。本杰明·迪斯雷利（Benjamin Disraeli）说过："我们通过语言实施对人的控制。"对选民和消费者来说，防这种诡计最好的办法，就是理清面前这句话真正的功能是什么。

## 事实之争，还是态度之争

争论可能来自双方对同一事实的信念不同，也可能来自对同一事实的态度不同；而双方用词情感色彩大不相同，又会让这种不确定变得更混乱。

假设 X 和 Y 在争是否要给谋杀罪立法死刑，分歧可能有三种：

- **纯粹事实分歧**：死刑事实上是否构成对谋杀的有效威慑。
- **纯粹态度分歧**：不管威慑作用多大，国家处死刑事犯是否正确。
- 两者都有：既不信它有效，又认为它不正当，或者在其中一个上面也谈不拢。

要化解事实加态度的争论，关键是先弄清真正的问题在哪。如果真正分歧是"死刑有没有用"，那第一步就是客观地确认事实——虽然做起来不容易；如果分歧在"国家授权死刑是否正确"，那么光在事实上达成一致，根本解决不了争论。

态度上的争论，有时源自对事实的信念不同，有时不是。关于赢球重不重要，体育作家格兰特兰德·赖斯（Grantland Rice）写道："当球星走进球场，/为其声名留下光芒，/这光芒不论输与赢，/只记录场上飞奔的身影。"教练文斯·隆巴蒂（Vince Lombardi）却说："赢球不是别的，它就是唯一（竞赛目标）。"这两种态度的分歧，根子是不是在信念不同？这个问题留给你想。原书提醒我们：光确认争论的本质，并不能让我们自动达成一致；但只有确认了真正的本质、看清了双方语言的不同功能，分歧才有解决的可能。

## 常见误解

- **"委婉一点，事实就变了"**：词换了，事实不一定变；但人的反应会被影响，这正是委婉语的力量，也是它的危险。
- **"只要查清事实，争论就该结束"**：如果分歧其实在态度上（比如国家该不该处死犯人），事实查清了也结束不了。
- **"带情绪的话一定不诚实"**：不一定。诗歌里情感语言很合适；问题是它在需要客观报道的场合会削弱客观性，或被用来操纵态度。

## 自测题（据原书第 3.2 节练习）

下面每组两句话，最可能表示的是一致还是歧见？如果是歧见，属于事实分歧、态度分歧，还是两者兼有？

1. a."糟糕的和平比战争更邪恶。"（塔西佗）b."最差劲的和平也强过最正义的战争。"（伊拉斯谟，1539）
2. a."及时行事，事半功倍。" b."迟做总比不做强。"
3. a."白人社会与贫民窟有密切的联系。白人组织创造，维持它们，又对其坐视不理。"（1968 年美国民骚乱全国委员会／克纳委员会）b."法官们不知道怎样恢复罪犯的社会名誉——因为根本就没人知道。"（安德鲁·冯·希尔施，1976）

<details>
<summary>展开答案</summary>

1. 态度分歧。塔西佗认为某些和平比战争更坏；伊拉斯谟认为再差的和平也胜过最正义的战争。两人对"和平与战争哪个更可取"持相反评价，不是在同一件事上有不同的事实信念。
2. 态度分歧（价值取向上的差异）。"及时行事，事半功倍"强调早做的好处；"迟做总比不做强"强调弥补胜过放弃。两句都在谈行动时机，但鼓励的方向和看重的东西不同，没有具体事实可判真假。
3. 这组里两句话的主题不同，谈不上同一问题上的分歧：前者谈白人社会对贫民窟的责任，是一个可以查证的事实性判断并带谴责；后者谈恢复罪犯社会名誉在实践上不可能。按本节标准，先要看它们是不是针对同一事实的信念或态度；这里更像各说各话，而非同一问题上的争论。
