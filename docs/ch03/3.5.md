# 3.5 定义的结构：外延与内涵

> **这节课解决什么困惑**："行星"这个词的意思，是水星、金星、地球这一串星星，还是"绕太阳运行的天体"这样一条标准？同一个意思为什么会有两种说法？

## 学习目标与先修概念

- **学完这课你能**：分清一个普遍词项的外延和内涵；解释为什么内涵决定外延而外延不决定内涵；认出外延定义与内涵定义各自的办法和短板。
- **先修概念**：3.4 讲的五种定义用途是按"定义拿来干什么"分的；这一课换一个角度，按"定义是怎么搭出来的"来看。

## 一个词的意义有两层

我们关心的是能用到一个以上对象上的词项，也就是**普遍词项**。"行星"就是一个：它同等地适用于水星、金星、地球、火星、木星、土星、天王星和海王星；冥王星不算，国际天文联合会已经把它划进"矮行星"。

说"行星"有意义，至少可以指两件事。第一，它指这些对象的全部汇集——提到行星，你想到的是水星到海王星这一组。这层叫**外延意义**（extensional meaning，也叫指谓意义）：一个普遍词项的外延，就是它正确适用的那些对象构成的集合。我说"所有行星都有椭圆轨道"，其实说的是火星有椭圆轨道、金星有椭圆轨道，等等。

第二层不问"有哪些对象"，而问"凭什么算"。同一类对象总有一些共同性质，正是这些性质让我们用同一个词去叫它们。知道这条标准，就算不知道全部对象，也算懂了这个词。这层叫**内涵意义**（intensional meaning，有时也叫 connotative meaning）：一个词项的内涵，是它指谓的所有对象共同具有、并且只有它们才具有的属性集。比如"摩天大楼"的内涵是"超过一定高度的建筑"，它的外延则包括纽约的世贸中心、芝加哥的希尔斯塔、上海环球金融中心、吉隆坡的国油双峰塔等等。

## 内涵决定外延，反过来不行

一个词项的外延，是由它的内涵决定的：凡满足那条标准的对象，都自动落进外延。"等边三角形"的内涵是"三条等长直线围成的平面图形"，它的外延就是所有且仅有这种图形的类。

反过来却不成立。"等角三角形"的内涵是"三条线相交形成等角的平面图形"，和"等边三角形"的标准完全不同，但两者的外延一模一样。由此可知：知道了外延，你并不能反推出内涵；内涵不同的词项可以外延相同，而外延不同的词项不可能有同样的内涵。

给内涵增加性质，通常就会缩小外延：从"人"到"活着的人"到"活着的二十岁以上的人"到"活着的二十岁以上出生在墨西哥的人"，每加一条，适用对象就少一圈。但别以为两者永远反向变化。看这一串："活着的人"→"活着的有脊骨的人"→"活着的有脊骨的不超过一千岁的人"→"活着的有脊骨的不超过一千岁的没有读完国会图书馆全部藏书的人"。内涵一路增加，外延却一点没少——我们能想到的每个人都还在这串词项里。所以准确的说法是：词项按内涵递增排列时，外延是非递增的；外延若有变化，方向与内涵相反。

外延还可以是空的。古希腊神话里柏勒洛丰杀死的那个吐火怪物（狮头、羊身、蛇尾，即奇美拉），我们完全懂"怪物"这类词的标准，但世上并没有它。由此常出现一种坏论证："'上帝'这个词不是无意义的，所以它有意义；按定义它的意思是全能至善的存在；所以全能至善的存在、也就是上帝，必然存在。"词有意义，只说明它有内涵，不等于它指谓的东西真的存在。这个区分是坎特伯雷的圣安瑟伦引进的，他以"本体论论证"闻名，但上面那个谬误并不是他的论证。一位当代批评家也犯了类似的错：他说低劣作品（kitsch）以展示粗鄙、卑劣、懦弱和邪恶来败坏人类境况，所以乌托邦可以定义为这个词项不再有所指的状态。他把意义与所指混为一谈了。许多有价值的词都没有所指，我们并不因此要求它们消失；万一将来乌托邦成真，我们恰恰需要用"低劣作品""粗鄙"这些词来表达庆幸。

## 用外延定义：把对象指出来

**外延定义**（也叫指称性定义）直接指出词项的外延。最直白的就是列举：说"桌子"意指这个，同时用手一指。这很有效，但麻烦不少。

第一，不同内涵的词项可以有完全相同的外延，就算你把对象列全了，也分不出你说的是哪个词——"等边三角形"和"等角三角形"就是例子。第二，很多类根本列不全："恒星"多到天文数字，"数"更是无穷无尽。于是只能举一部分例子，可任意对象身上都挂着许多性质，一个例子可能同时属于好几个类。拿帝国大厦解释"摩天大楼"，你也可能指的是"二十世纪的伟大建筑""曼哈顿的昂贵房地产"或"纽约市的地标"；再把克莱斯勒大厦和川普大楼加上，还是分不清。

通过子类列举有时会好一些，比如把"脊椎动物"定义为两栖动物、鸟类、鱼类、哺乳动物和爬行动物，列全了心里踏实，但仍没把"脊椎动物"的意义说透。

**实指定义**（示范定义）靠姿势：指着桌子说"'桌子'这个词意指这个"。它的局限很具体：只能指看得见的东西，在内陆山谷里就没法实指地定义"海洋"；而且指一张桌子，同时也指着它的一部分、颜色、大小、形状、质料，甚至桌子后面的灯和墙。加一句描述可以缓解，比如"'桌子'意指这件家具"，但这已经预设你懂"家具"了，这种叫**准实指定义**。实指定义还永远定义不了没有外延的词："独角兽"并不指任何东西，但这句话完全有意义而且是真的。顺带说一句，我们最初学语言靠的是观察和模仿，并不是靠定义。

## 用内涵定义：把标准说出来

内涵定义给出的是"凭什么算"的标准。这里要分清三种内涵。说话者心里以为的属性集，叫**主观内涵**，因人而异、因时而异，不适合做定义；一个词外延中的对象实际上共同拥有的全部属性，叫**客观内涵**——比如圆的面积比任何同周长的封闭平面图形都大，这条性质很多人用"圆"时根本没想到，要知道全部属性得全知，谁也做不到；真正能拿来定义的是**归约内涵**：大家公开承认、用来判断某个对象算不算这个词的例子的那条标准，比如"圆是封闭的平面曲线，线上各点到圆心的距离都相等"。本书说"内涵"时，指的就是归约内涵。

内涵定义有几种常见办法。**同义定义**拿一个意义已懂的词来解释：词典把"谚（adage）"定义为"谚语（proverb）"，把"腼腆（bashful）"定义为"害羞（shy）"；学外语时"chat"就是"猫"、"amigo"就是"朋友"，离不开它。但它有限度：很多词并没有严格同义词，翻译常抓不住原作的精神，意大利谚语干脆说"翻译者就是窜改者"；如果概念本身陌生，给个同义词还是一样不懂，理论定义和精确定义靠它就够呛。

**操作定义**把词和一组可描述、可重复的操作绑在一起。这个说法是诺贝尔物理学奖得主布里奇曼 1927 年在《现代物理学的逻辑》里首次使用的。爱因斯坦的相对论成功后，"空间""时间"不能再按牛顿那种抽象方式定义，于是有人主张用测量距离和时间的操作来定义它们：某个长度数值，就由相应的测量程序产生的结果来定义。有些心理学家也试着用只涉及行为或观察的操作，代替"感觉""心灵"的抽象定义。

适用范围最广的是**属加种差定义**，留到下一课细讲。把 3.4 的五种用途和这一课的六种方法（外延三种、内涵三种）合起来看，定义这件事就有了完整的地图。

## 常见误解

- **"'行星'的意思就是那一串星星"**：这只说了一半。那一串是外延；"绕日运行、质量足够大、清空轨道"那些条件才是内涵。
- **"把例子列全了，定义就完成了"**：不全列不出来；列一部分又分不清你指的是哪个类；举"帝国大厦"既可能是摩天大楼，也可能是曼哈顿地产。
- **"词有内涵，就说明它指的东西存在"**：不对。"独角兽"没有外延，我们照样懂它，也照样能有意义地说"不存在独角兽"。

1. 动物，猫科动物，猞猁，哺乳动物，脊椎动物，野猫。
2. 酒精饮料，饮料，香槟，精制白葡萄酒，白葡萄酒，葡萄酒。
3. 整数，数，正整数，质数，有理数，实数。
