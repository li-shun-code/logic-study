# 3.3 论争与含混性

> **这节课解决什么困惑**：两个人为一件事吵得面红耳赤，有没有可能他们其实在说两件不同的事？怎么判断这场争吵是"真吵"还是"吵错了"？

## 学习目标与先修概念

- **学完这课你能**：分清三类争论——实质争论、纯粹语词争论、看似语词实则实质的争论；用"澄清关键词义"这个动作去检验一场争论属于哪一类。
- **先修概念**：3.2 的事实分歧与态度分歧；含混的词项（有多个意思，双方却没察觉）正是争论的温床。

## 争论为什么会发生

有些争论——不管是在争信念还是争态度——是**实质争论**，真的有分歧。还有些争论只是**言辞之争**：冲突完全来自语言的误解。争论中的词项可能有多个意思，也就是**含混**的，而双方都没发现。要揭开并解决言辞之争，就得找出这种含混，把关键词的不同含义区分清楚。

## 三类争论

**第一类，明显的实质争论。** A 支持扬基队（Yankees），B 支持红袜队（Red Sox），他们之间的争论是实质争论，虽然大多属于态度上的分歧。C 认为迈阿密在里约热内卢以南，D 不这么认为，这也是实质争论——它争的是地理事实，一张好地图就能解决。

**第二类，纯粹的言辞之争。** 这里其实没有实质分歧，只要把某个词或短语的意思统一，表面的冲突就消失了。一棵树在荒野中倒下，没有任何人听见，F 说它没发出声音，G 说它发出了声音。如果"声音"指的是人的听觉结果，两人都会同意：没有声音；如果"声音"只是指空气中的震动，两人都会同意：树发出了声音。弄清"声音"在这里是什么意思，争论就没了。

**第三类，看似言辞、实则实质。** 这类更复杂：里面确实有对词用法的误解，但误解澄清之后，仍然存在超出语词含义的分歧。比如，有露骨性活动镜头的影片，该不该当作"色情作品"处理？J 认为露骨就使它成了邪恶的色情作品；K 考虑到细腻的情感和美学价值，坚持它是真正的艺术，根本不是色情作品。"色情作品"这个词的含混当然要澄清，但即使澄清了，两人对这部影片的评价很可能还是不一致——一部电影是不是"色情电影"可以通过定义来判定，但更深的分歧会在定义之后露出来。值得注意的是，"色情电影"是个贬义词，讨厌它的 J 和支持它的 K 对这个词的用法不同，但在两种用法里它的情感意义都极其负面；他们连"什么才算色情电影"这个负面词的使用标准都有分歧。

## 怎么给一场争论分类

面对一场争论，先问一个问题：**里面有没有可以通过澄清多种意义而消除的含混？**

- 如果有，再问：把这个语言问题清掉，争论是不是就解决了？
  - 解决了 → 这是**纯粹语词争论**。
  - 没解决 → 这是一个披着语词争论外衣的**实质争论**。
- 如果本来就没有词义含混，那通常就是明显的实质争论。

这套顺序很重要：不要急着站队，先看看双方是不是在用同一个词指不同的东西。树倒下有没有声音的例子说明，很多"争吵"只要统一词义就烟消云散；而色情电影的例子说明，词义统一之后还可能藏着真正的价值对立。

## 常见误解

- **"吵起来就是有实质分歧"**：不一定。荒野里树倒下有没有声音，只是"声音"指听觉还是指空气振动的分歧。
- **"只要把词定义清楚，争论就结束了"**：不一定。露骨影片是不是艺术，定义清楚"色情作品"之后，评价上的对立还在。
- **"言辞之争是浪费时间，不用管"**：不对。先辨明它是不是言辞之争，本身就是解决争论的第一步。

## 自测题（据原书第 3.3 节练习 B，Dai 与 Nate 的争论）

讨论下面这些争论：如果是明显的实质争论，指出双方各自断定的命题；如果是纯粹言辞之争，通过解释关键词的不同意义来解决它；如果看似言辞之争实则实质，找出歧义，说明其中真正的分歧。

1. 戴：皮特·罗斯是棒球历史上最伟大的得分手，他比联盟其他主要球员的得分都多。奈：不，汉克·阿伦才配得上那个称号，他比联盟其他主要球员的本垒打都多。
2. 戴：贝蒂终于甩掉了那辆旧雪佛兰，为自己买了辆新汽车，她现在开的是别克。奈：不，贝蒂没有给自己买新车，那辆别克足足有三年寿命了。
3. 戴：在那种宴会中，供应烤牛肉是不得体（in bad taste）的，有印度人出席，吃牛肉有悖于他们的宗教信仰。奈：难吃，没有的事！这是我很久以来所吃到的最美味的肉了，我认为它非常可口！

1. 纯粹言辞之争（关键词义不同）。戴说的"得分"是棒球统计里的得分（runs），奈说的却是本垒打（home runs）。统一"最伟大"按哪种数据来衡量，分歧就能解决；若两人都同意按得分算，戴对；按本垒打算，奈对。
2. 纯粹言辞之争。"新"的词义不同：戴指的是"对贝蒂来说是新买的、换掉旧车的"，奈指的是"出厂年份很近的"。说清"新汽车"指哪种意义，争论就消失了。
3. 看似言辞之争，实则含混加实质分歧。"不得体（in bad taste）"在戴的话里是"不合礼仪、不恰当"，在奈的理解里却成了"味道不好吃"。澄清后，奈的应和其实没有回应戴的论点；而戴关于"有印度人出席时吃牛肉违背其信仰"的事实与礼节判断，仍可继续争论，这已经超出语词含义，属于实质分歧。
