# 3.3 论争与含混性

> **这节课解决什么困惑**：有些争论吵了半天，最后发现只是在争一个词的意思？怎么判断一场争论是实质之争，还是言辞之争？

## 学习目标与先修概念

- **学完这课你能**：分清实质论争、纯粹言辞之争，以及表面是言辞之争、实际是实质之争；遇到论争时先找关键词项的含混性，再看澄清之后分歧是否还在。
- **先修概念**：3.2 的事实分歧与态度分歧——论争的内容可以是信念，也可以是态度。

## 先分清三类论争

许多论争——无论是关于信念的还是态度的——都是实质论争。还有些只是纯粹的言辞之争，由语言误解引起。论争中的词项可能有多个意思（含混的），而双方都没察觉。要揭示和解决言辞之争，就得找出含混性，区别并澄清关键词项的不同含义。

第一类，**明显的实质论争**。A 支持扬基队（Yankees），B 支持红袜队（Red Sox），他们的论争是实质论争，虽然大多是态度上的。C 认为迈阿密在里约热内卢南部，D 不这么认为，这也是实质论争——争的是地理事实，一张好地图就能解决。

第二类，**纯粹的言辞之争**。这里没有实质歧见，表面的冲突只要统一对某些词汇或短语的理解就能解决。一棵树在荒野中倒下，没人听到，F 认为它没有发出声音，G 认为它发出了声音。如果"声音"指人类听觉的结果，双方都会同意没有声音；如果"声音"只是空气中的震动，双方都会同意树发出了声音。弄清"声音"的意思，分歧就消失了。

第三类，**表面是言辞之争，实际上是实质之争**。这类论争里确实有词项用法上的误解，但误解澄清之后，仍存在超出语词含义的歧见。比如有露骨性活动镜头的影片该不该作为"色情作品"处理？J 认为露骨使它成了邪恶的色情作品；K 考虑到细腻的情感和美学价值，认为它是真正的艺术，根本不是色情作品。双方的歧见显然在"色情作品"一词的意义上；但即使把这个词的含混性彻底澄清，双方对影片的评价很可能仍然有分歧。"色情电影"是贬义词：讨厌它的 J 和支持的 K 对这个词各持一种理解，在"色情电影"这个负面词汇的使用标准上也有分歧。关于一部电影是否为"色情电影"的争论，可以通过定义解决；但更深的歧见也可能由此暴露出来。

## 遇到论争先问两步

面对一场论争，先问：其中是否存在可以通过澄清多种意义而消除的含混性？如果有，再问：清掉这个语言问题，论争就解决了吗？

解决了，就是纯粹言辞上的；解决不了，面对的就是一场披着言辞之争外衣的实质论争。

## 自测题（据原书第 3.3 节练习 B）

1. 讨论这场争论，指出它属于哪类论争："戴叶：皮特·罗斯是棒球历史上最伟大的得分手。他比联盟的其他主要球员的得分都多。／奈特：不，汉克·阿伦才配得上那个称号。他比联盟的其他主要球员的本垒打都多。"
2. 讨论这场争论："戴：安娜是一个优秀学生。她对任何事情都有强烈的兴趣，并且在班里提出的问题都是非常有才智的。／奈：安娜是我迄今所见到的最差劲的学生之一。她从不按时交作业。"
3. 讨论这场争论："戴：贝蒂终于甩掉了那辆旧雪佛兰，为自己买了辆新汽车。她现在开的是别克。／奈：不，贝蒂没有给自己买新车。那辆别克足足有三年寿命了。"

<summary>展开答案</summary>

1. 这是实质论争，而且表面还藏着一个词项上的误会。戴叶说的是"得分手"——以得分多少衡量；奈特说的是"本垒打"——以本垒打多少衡量。两人用的是不同标准，这是需要澄清的歧义；但即使把"最伟大"按其中一种标准说清，两人对"谁更伟大"的评价仍会不同，所以属于以言辞面貌出现的实质论争。
2. 这是实质论争，争的是"优秀学生"的评判标准。戴看的是兴趣和提问的才智，奈看的是是否按时交作业；两人对同一个学生给出相反评价，分歧在评价标准上，不是某个词的歧义。
3. 这是纯粹言辞之争。争点是"新车"的意思：戴说的是对贝蒂而言是"刚换来的车"，奈说的是车本身的车龄——那辆别克已经三年了。统一"新车"指"刚买来的"还是"出厂不久的"，表面的冲突即可消解。
