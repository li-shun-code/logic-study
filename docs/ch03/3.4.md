# 3.4 定义不只是"这个词什么意思"

> **这节课解决什么困惑**："地球是圆的"和"圆的就是像地球这样的"，两个定义怎么完全不是一回事？

## 定义定义什么

先纠正一个直觉：定义的是**符号（词项）**，不是对象。你不能给一张桌子下定义，只能给"桌子"这个词下定义。

被定义的词叫**被定义项 definiendum**，用来解释它的那串词叫**定义项 definiens**。

> "三角形" = 由三条线段围成的平面图形。

"三角形"是被定义项；"由三条线段围成的平面图形"是定义项。

## 五种定义用途

同一个"定义"动作，可以出于五种不同目的：

| 类型 | 在做什么 | 例子 |
| --- | --- | --- |
| 规定性定义 stipulative | 约定一个新用法 | "我把‘ googol’定义为 10 的 100 次方" |
| 词典定义 dictionary | 报告已有的用法 | "‘法学’是研究法律的学科" |
| 精确化定义 precisifying | 划清模糊词的边界 | "‘秃头’指头发少于……" |
| 理论定义 theoretical | 在理论中指定含义 | "黑洞是引力强到光也无法逃逸的时空区域" |
| 说服性定义 persuasive | 用定义改变态度 | "民主就是听我的意见"（伪装成词典定义） |

## 为什么区分这五种很重要

词典定义可以有对错——它要符合实际用法。规定性定义没有对错，只有方不方便——你可以规定任何词的意思，但不能要求别人照办。

最危险的是**说服性定义**：它披着"定义"的外衣，偷偷塞进评价。比如：

> "真正的自由就是不受任何约束。"

这不是在报告"自由"的用法，而是在推一种政治立场——却伪装成定义。识别它的方法：**问这个定义是在描述已有用法，还是在要求你接受某种评价。**

## googol、黑洞与夸克

- **googol** 是数学家规定出来的新词，纯规定性定义；
- **黑洞** 最初是理论物理中的假设，后来被观测支持——理论定义；
- **夸克** 也是理论定义：你不能直接看见它，它在理论里的角色定义了它。

## 自测题

判断下面定义属于哪种用途，并指出哪个最可能在误导人：

1. "在本课程中，‘有效’特指演绎论证的保真性。"
2. "‘孤独’是指一个人每周社交少于两次的状态。"
3. "自由就是想做什么就做什么。"

<details>
<summary>展开答案</summary>

1. 规定性定义——在课程范围内约定术语用法。
2. 精确化定义——给模糊词划一条人为边界。
3. 说服性定义——它表面在定义，实际在推广一种特定政治态度；忽略了"自由"在哲学和法律中的多种用法。最可能误导人。
</details>
