# 从读不下去的地方开始

这本书的内容多、例子密、术语像墙一样立在最前面。这个网站只做一件事：**把每一节改写成一条你能走完的学习路线**。

## 这本书讲什么

全书按推理的形式分成五大模块：

- **推理的基本语言**：什么是论证、怎样分析论证、语言与定义怎样影响推理；
- **三段论逻辑**：从"所有法律都是规则"这类句子出发，学会传统演绎；
- **现代符号逻辑**：把论证写成公式，用真值表和推导规则检查；
- **类比与因果**：处理日常和科学里最常见的非演绎推理；
- **科学与概率**：假说怎样被检验，概率怎样计算。

完整的 14 章顺序见下方章节总览。你现在不必记住这些名字，只要知道：每一课都会从一个困惑开始，而不是从定义开始。

## 怎么用这个网站

1. 先看 **[前言：这本书该怎么读](/preface/)**，明白原书的安排和术语套路；
2. 再进入 **[1.1 逻辑学的基本概念](/ch01/1.1)**，从"什么算论证"开始；
3. 每一课先看"这节课解决什么困惑"，再看推导，最后做自测；答案默认折叠，先自己想再展开；
4. 拿不准某个词时，查 **[中英文术语表](/reference/terms)**。

这个网站不记录账号、不记录进度，也不追踪你。刷新、离线读、打印都可以。
