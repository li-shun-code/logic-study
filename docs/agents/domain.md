# Domain Docs

Before exploring, read the root `GLOSSARY.md` or `GLOSSARY-MAP.md`, plus
relevant ADRs in `docs/adr/`.

This repo uses a single context: keep the glossary in `GLOSSARY.md` and
decisions in `docs/adr/`. Create these files lazily, when a domain term is
resolved or a decision warrants an ADR. Keep implementation details out of the
glossary.
