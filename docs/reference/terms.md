# 中英文术语表

这份表只收录最容易混淆、以及后面反复出现的词。每条给出"它回答什么问题"和"别和谁混"。按章节顺序排列，方便边读边查。

## 第 1 章：逻辑学的基本概念

### 逻辑学 logic
- **回答什么**：区分正确推理与不正确推理的方法。
- **别混**：不是"吵架的艺术"，也不是"研究思维的科学史"。

### 命题 proposition
- **回答什么**：一个能判定真假的陈述。
- **别混**：句子 sentence 可以没有真假（疑问、命令、感叹）；命题才有真假。

### 简单命题 / 复合命题 simple / compound proposition
- **回答什么**：命题是否由其他命题用"并且、或者、如果……那么"连接而成。
- **别混**："张三和李四爬山"仍是简单命题；复合命题要连接两个完整命题。

### 论证 argument
- **回答什么**：从若干前提推出结论的推理结构。
- **别混**：不是"争辩"，也不等于"一串理由"。必须有结论被声称由前提支持。

### 前提 premise / 结论 conclusion
- **回答什么**：论证中"给出的理由"和"被推出的主张"。
- **别混**：识别它们靠语义和语境，不靠位置——结论也可以在开头。

### 演绎 deduction / 归纳 induction
- **回答什么**：前提对结论的支持是"必然"还是"大概率"。
- **别混**：演绎不保证前提为真，只保证"如果前提真，结论不可能假"。

### 有效 valid / 可靠 sound
- **回答什么**：演绎论证的形式是否保真；以及形式保真且前提实际为真。
- **别混**：有效只评形式，不评事实；可靠 = 有效 + 前提真。

## 第 2 章：论证的分析

### 论证的重塑 paraphrasing
- **回答什么**：把省略的前提补出来，把绕弯的话改写清楚。
- **别混**：不是"换一种说法"，而是**忠实**地显出推理结构。

### 论证图 argument diagram
- **回答什么**：用编号和箭头表示前提如何支持结论。
- **别混**：箭头方向是"支持"，不是"时间先后"。

### 独立支持 / 联合支持 independent / joint support
- **回答什么**：几个前提是各自单独支撑结论，还是合起来才支撑。
- **别混**：两个前提互相依赖时，不能各画一条独立箭头。

## 第 3 章：语言与定义

### 信息性 / 表达性 / 指令性功能 informative / expressive / directive
- **回答什么**：一段话是在陈述事实、表达情绪，还是在要求行动。
- **别混**：同一句话可能同时有两种功能，形式不等于功能。

### 情感色彩 emotive / 中性语言 neutral language
- **回答什么**：词语是否在描述之外附加了赞许或贬斥。
- **别混**：带感情的词不一定错；关键是它有没有替代证据。

### 实质争论 / 语词争论 substantive / verbal dispute
- **回答什么**：分歧在于事实，还是在于某个词怎么定义。
- **别混**：看起来是语词争论，有时背后藏着实质分歧。

### 定义 definition
- **回答什么**：说明一个符号（词）的意义，而不是给物体下定义。
- **别混**：定义的是词项 term，不是具体对象 object。

### 规定的 / 词典的 / 精确化的 / 理论的 / 说服性定义 stipulative / dictionary / precisifying / theoretical / persuasive
- **回答什么**：一个定义分别想做什么——约定新用法、报告已有用法、划清边界、提出理论、改变态度。
- **别混**：说服性定义伪装成词典定义时最容易误导人。

### 外延 / 内涵 extension / intension
- **回答什么**：词适用哪些对象；词暗示什么属性。
- **别混**："等边三角形"和"等角三角形"外延相同，内涵不同。

### 属加种差 genus and difference
- **回答什么**：用一个词的上位类加上它区别于同类的属性来下定义。
- **别混**：循环定义、过宽过窄、用比喻定义，都违反定义规则。
