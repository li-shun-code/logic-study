# 术语表

这份表只收录最容易混淆、后面又反复出现的词。每条说清两件事：它回答什么问题、别和谁混。按章节顺序排列，方便边读边查。英文只在第一次出现时点一下。

## 第 1 章：逻辑学的基本概念

### 逻辑学 logic
- **回答什么**：区分正确推理与不正确推理的方法。
- **别混**：不是吵架的艺术，也不是关于思维的历史。

### 命题 proposition
- **回答什么**：断定事实、因而有真假的句子。
- **别混**：疑问句、命令句、感叹句没有真假，不是命题。

### 简单命题 / 复合命题 simple / compound proposition
- **回答什么**：命题是否由"并且、或者、如果……那么"把几个命题连起来。
- **别混**："张三和李四爬山"仍是简单命题；复合命题连接的是两个完整命题。

### 论证 argument
- **回答什么**：结论被声称由前提支持的一组命题。
- **别混**：不是日常意义的争辩；必须真的有前提支持结论的结构。

### 前提 premise / 结论 conclusion
- **回答什么**：论证里的理由和被推出的主张。
- **别混**：识别靠语义和语境，不靠位置——结论也可以写在开头。

### 演绎 deduction / 归纳 induction
- **回答什么**：前提对结论的支持是"决定性"还是"非决定性"。
- **别混**：演绎不保证前提真，只保证"前提真时结论不可能假"。

### 有效 valid / 可靠 sound
- **回答什么**：演绎论证的形式是否保真；以及形式保真且前提实际为真。
- **别混**：有效只评形式，不评事实；可靠 = 有效 + 前提真。

## 第 2 章：论证的分析

### 论证的重塑 paraphrasing
- **回答什么**：把省略的前提补出来，把绕弯的话改写清楚。
- **别混**：不是随意换说法，必须忠实于原意。

### 论证图 argument diagram
- **回答什么**：用编号和箭头表示前提如何支持结论。
- **别混**：箭头表示"支持"，不是时间先后。

### 独立支持 / 联合支持 independent / joint support
- **回答什么**：几个前提是各自单独支撑结论，还是合起来才支撑。
- **别混**：互相依赖的前提不能各画一条独立箭头。

## 第 3 章：语言与定义

### 信息性 / 表达性 / 指令性 informative / expressive / directive
- **回答什么**：一段话是在陈述事实、表达情绪，还是在要求行动。
- **别混**：同一句话可能同时有几种功能；形式不等于功能。

### 情感色彩 emotive / 中性语言 neutral language
- **回答什么**：词语是否在描述之外附加了赞许或贬斥。
- **别混**：带感情的词不一定错，关键是它有没有替代证据。

### 实质争论 / 语词争论 substantive / verbal dispute
- **回答什么**：分歧在事实，还是在某个词怎么定义。
- **别混**：看似语词争论，背后有时藏着实质分歧。

### 定义 definition
- **回答什么**：说明一个符号（词）的意义，不是给物体下定义。
- **别混**：定义的是词项，不是具体对象。

### 规定 / 词典 / 精确 / 理论 / 说服定义 stipulative / dictionary / precisifying / theoretical / persuasive
- **回答什么**：一个定义想做什么——约定新用法、报告已有用法、划清边界、概括理论、改变态度。
- **别混**：说服定义伪装成词典定义时最容易误导人。

### 外延 / 内涵 extension / intension
- **回答什么**：词适用于哪些对象；词要求什么属性。
- **别混**："等边三角形"和"等角三角形"外延相同，内涵不同。

### 属加种差 genus and difference
- **回答什么**：用上位类加上区别于同类的属性来下定义。
- **别混**：循环、过宽过窄、比喻定义，都违反规则。
