# 这本书该怎么读

很多人翻开《逻辑学导论》的第一反应是：例子太多、术语太密、不知道重点在哪。这不是你的问题——原书信息量大、翻译腔重，硬啃确实容易半途而废。这里先给你一张地图。

## 这本书想教会你什么

柯匹、科恩和罗迪奇写的不是逻辑史，而是一本**训练判断力**的书。它把"推理靠不靠得住"这件事拆成可练习的动作：

- 看到一段话，先判断作者到底想让你接受什么；
- 把散落在句子里的理由和结论摆出来；
- 分清一段推理要的是"必然成立"还是"很可能成立"；
- 识别语言里的情绪、模糊和定义陷阱；
- 用形式工具（三段论、真值表、量化）检查推理；
- 面对因果、类比、科学假说和概率时，知道该怎样怀疑。

## 为什么原书难读

每节都先给抽象定义，再塞进大量历史和报刊例子，最后甩一串练习。读者通常卡在两个地方：

1. **看不出定义和例子的关系**——不知道那一长串例子到底在说明哪一条；
2. **前面的没消化，后面的术语又叠上来**——读到符号逻辑时早已迷失。

本站的改写办法是顺着你的脑子走：**每课从具体困惑开场，在讲解中带出定义，最后用原书练习把定义练一遍。**

## 三种你会反复用的工具

- **论证图**：给前提编号，用箭头画出谁支持谁。看见结构，比背术语管用。
- **定义卡片**：每个术语只记两件事——它回答什么问题、它和谁容易混。完整版见 [术语表](/reference/terms)。
- **自测题**：每课末尾先自己答，再展开答案。逻辑不是看懂的，是做出来的。

## 关于术语与例子

全书例子都来自原书——历史、报刊、法庭意见、科学报告，什么都有。它们不是为了让你记住某个案子，而是为了让你看见同一种推理骨架换了内容之后长什么样。术语以白话讲解为主，英文只在第一次出现时点一下。
