# 这本书的前言：你不必硬啃

很多人翻开《逻辑学导论》的第一反应是：例子太多、术语太多、不知道重点在哪。这里先给你一张地图，再正式进入第一讲。

## 这本书想教会你什么

柯匹、科恩和罗迪奇写的不是"逻辑史书"，而是一本**训练判断力**的书。它把判断力拆成可练习的动作：

- 看到一段话，先判断作者究竟在证明什么；
- 把散落在句子里的前提和结论摆出来；
- 分清这段话要的是"必然成立"还是"很可能成立"；
- 识别语言里的情绪、模糊和定义陷阱；
- 用形式工具（三段论、真值表、量化）检查推理；
- 面对因果、类比、科学假说和概率时知道该怎么怀疑。

## 原书的结构为什么难读

每节都先给出抽象定义，再塞进大量历史和报刊例子，最后给练习题。读者往往卡在两个地方：

1. **看不出定义和例子之间的关系**——不知道例子到底在说明哪一条；
2. **前面没消化，后面术语又叠上来**——读到第 8 章符号逻辑时已经迷失。

本站的改写策略是反过来：**每一讲先用一个具体困惑开场，在推导中给出定义，最后用自测把定义练一遍。**

## 三种你要反复用的工具

- **论证图**：给前提编号，用箭头画出谁支持谁。看见结构，比记住术语有用。
- **定义卡片**：每个术语只记两件事——它回答什么问题、它和谁容易混。完整版见[术语表](/reference/terms)。
- **自测题**：每课末尾先自己答，再展开答案。逻辑不是看懂的，是做出来的。

## 关于术语

本书的"命题"不是语法课里的"句子"，"论证"也不是"吵架"，"真"和"有效"更不是一回事。这些词在中文里都有日常含义，但在逻辑学里有严格用法。第一次遇到时别用日常意思去套，按课程里的定义来。
