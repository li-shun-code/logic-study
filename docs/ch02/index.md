## 本章讲什么

这一章接着上一章"找论证"往下走：找到了前提和结论，还要把它们之间的关系摆清楚。四课练的是同一件事，角度各不相同。

2.1 讲**重塑**：前提多、顺序乱、意思含糊时，用清楚的话按逻辑顺序重述，既可以把明确断言的东西列整齐，也可以把暗含的前提请出来——但绝不替作者添他没想过的主张。最高法院关于得州鸡奸法的判决重塑成四步，哈代那句"阿基米德被永记、埃斯库罗斯被遗忘"重塑成七步，就是两种典型。

2.2 讲**图示法**：编号画圈、箭头表支持，结论放下方，同层前提写同一行。它让"并排支持""接力支持""合起来才支持"一眼可见，也能显示一个前提带出两个结论、上一课的结论成了下一课的前提。

2.3 处理**复杂语段**：命题换个词重复出现、浓缩成一个短语、中间结论还要去撑最终结论。图示有用，但没有机械画法；同一段话可以有几种合理的图。动物实验、大爆炸、太阳能汽车和《新英格兰医学杂志》的编辑方针，展示了怎么把网理清。

2.4 换到**自己推理**：给定线索，用排除法和矩阵推出答案，用"回溯分析"从现在推过去。推理谜题信息给足、答案明确，和描述不准、信息不全的现实问题不同，却是训练推理链的好工具。

四课合起来：先摆清楚（重塑、图示），再理清长段落，最后自己动手推理。会分析，才谈得上评价。

## 关键术语

| 术语 | 英文 | 一句话 |
| --- | --- | --- |
| 重塑 | paraphrase | 用清楚的语言、按逻辑顺序重述命题，且忠实原意 |
| 图示法 | argument diagram | 圆圈编号加箭头，直观展示前提与结论的支持关系 |
| 独立支持 | independent support | 每个前提单独就能支持结论 |
| 联合支持 | joint support | 几个前提合起来才支持结论 |
| 相对 | relative | 前提与结论是相对身份：一个论证的结论可做另一个的前提 |
| 隐含前提 | implicit premise | 论证实际依赖、却没有明说出来的前提 |
| 中间结论 / 分结论 | intermediate conclusion | 既被前提支持，又去支持最终结论的命题 |
| 矩阵 | matrix | 用行列格子记录可能选项和排除、确定结果的图 |
| 回溯分析 | retrograde analysis | 从当前状态推断其起因或过去状况的推理 |
