> 本章共 4 课。核心动作只有一个：把混乱的话摆成清楚的结构。

## 本章回顾

这一章练的是同一件事：把一段话里散落的命题摆成"谁支持谁"的结构。2.1 教你把省略的前提补出来——作者没说的那半句，常常才是论证的地基。2.2 引入论证图：给命题编号，用箭头表示支持关系，结论写在最下面；独立性（各自单独支持）和联合性（合起来才支持）的区别，决定了你反驳时要拆哪一根。

2.3 处理真实文本里的麻烦——前提重复出现、几个前提挤在一起、中间结论还要去支持后面的结论。2.4 用推理题把这套动作练成直觉：当你能熟练地找结论、补隐含前提、画结构图，再去评价推理对不对，就有了牢靠的起点。

## 关键术语

| 术语 | 英文 | 一句话 |
| --- | --- | --- |
| 论证重塑 | paraphrasing | 用清楚的语言重写论证，补全隐含前提 |
| 论证图 | argument diagram | 用编号和箭头表示前提对结论的支持关系 |
| 独立支持 | independent support | 每个前提单独就能支持结论 |
| 联合支持 | joint support | 几个前提合起来才支持结论 |
| 中间结论 | intermediate conclusion | 既被前提支持，又去支持最终结论的命题 |
| 隐含前提 | implicit premise | 作者未明说但论证必须依赖的前提 |
