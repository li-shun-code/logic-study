# 2.2 用图看清前提怎么支撑结论

> **这节课解决什么困惑**：三个前提一起出现，它们是各自单独支持结论，还是必须合起来才有用？

## 先看一个混乱的段落

> "我不该被扣工资。我按时完成了任务，而且我提前沟通了延迟的原因，何况公司制度里根本没有扣工资的条款。"

三条理由都在支持"不该被扣工资"。但它们的支持方式可能不同：
- "按时完成任务"可能**单独**就足以支持；
- "制度没有条款"也许单独够，也许需要和其他理由合起来才够。

搞清楚支持方式，才能判断论证强弱。

## 论证图的画法

1. 给每个命题编号，写在圆圈或方框里；
2. 结论写在最下面；
3. 用箭头从前提指向它所支持的结论。

独立支持画成：

```
(1) 按时完成  (2) 提前沟通  (3) 制度无条款
     ↓            ↓             ↓
        → (4) 不该被扣工资 ←
```

联合支持画成：

```
(1) 尾气污染  (2) 噪声扰民  (3) 事故太多
       ↘          ↓          ↙
          (4) 应限制开车
```

区别：独立支持里，每个前提单独就是理由；联合支持里，前提们**合起来**才构成理由。

## 中间结论

复杂论证里，一个命题既被别的前提支持，又去支持最终结论。它叫**中间结论**：

```
(1) 排放增加  (2) 植被减少
       ↘         ↙
        (3) 生态恶化   ← 中间结论
             ↓
        (4) 应干预
```

识别中间结论的诀窍：看一个命题有没有"既是箭头终点，又是箭头起点"。

## 同一组前提支持两个结论

看马克思《资本论》序言里的思路：一个历史学家可能用同样的史料既支持"某个事件发生了"，又支持"该事件有某种意义"。画成图：

```
(1) 史料 A  (2) 史料 B
     ↘       ↙
   (3) 事件发生了
        ↓
   (4) 事件意义重大
```

同一组前提可以分叉，走向不同的结论。画图能让你看见"哪些前提被重复利用"。

## 为什么要画图

因为文字是线性的，而推理结构是网状的。把线性的话摊成图，你会发现：
- 哪些前提是多余的；
- 哪一环缺少支撑；
- 作者其实换了好几个不同的论证，却写在一段里。

## 自测题

给下面这段话画论证图：

> "这个方案应该被否决。它预算超支，而且技术路线不可行。如果技术不可行，投入再多也得不到成果。"

<details>
<summary>展开答案</summary>

1. 方案预算超支
2. 方案技术路线不可行
3. 技术不可行则投入再多也无成果
4. 方案应该被否决

图示：
```
(1) 预算超支  (2) 技术不可行
     ↓            ↓
      ↘     (3) 无成果 ↙   （(2)+(3) 联合推出）
             ↓
        (4) 应否决
```
(1) 独立支持 (4)；(2) 与 (3) 联合支持 (4)。
</details>
