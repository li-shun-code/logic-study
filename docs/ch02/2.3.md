# 2.3 对付长段落：重复前提与集中前提

> **这节课解决什么困惑**：一整页的论证性文字，怎么下手分析？

## 长段落没什么可怕的

长段落只是短段落的叠加。关键动作还是两个：**编号、画图**。额外要注意两种结构。

## 重复前提

作者有时会把同一个前提换几种说法反复讲：

> "这项政策不合理。它成本高。它需要大量财政投入。它会花掉纳税人的钱。"

"成本高""需要大量财政投入""花纳税人的钱"是同一个意思。**编号时只记一次**，否则论证图会看起来有三个理由，其实只有一个。

## 集中前提

有时，作者先把一堆前提堆出来，最后才给结论：

> "宇宙大爆炸理论面临挑战。星系旋转曲线与预测不符，宇宙微波背景辐射的某些数据异常，轻元素丰度也与模型有偏差。"

三个前提集中出现，共同支持"面临挑战"。画图时把它们并列，箭头汇到结论。

##  Solar car 例子里的多层结构

看这个论证的骨架：

> "推广太阳能汽车是必要的。它不排放尾气，能减少城市污染。油价持续上涨，能源安全受威胁。而且太阳能技术已经成熟，成本开始下降。"

拆开看：
- 环保理由：不排放尾气 → 减少污染 → 应推广
- 能源理由：油价涨 + 能源不安全 → 应推广
- 可行性理由：技术成熟 + 成本下降 → 应推广

三条路线汇到同一个结论。这是一张有三条支路的图。逐条编号，别让它们混在一起。

## 处理长段落的操作顺序

1. **先找结论**，用"作者想让我相信什么"定位；
2. **编号命题**，每个编号只写一个完整命题；
3. **合并重复**，同一意思只留一个编号；
4. **画箭头**，从前提指向它支持的对象；
5. **检查缺环**，看有没有没被支持的中间结论。

## 自测题

把下面的段落拆成论证图，并指出有无重复前提：

> "我们应当反对这项工程。它会破坏湿地生态。湿地一旦破坏就很难恢复。而且它会让当地居民失去生计，居民失业是严重的社会问题。再说，它经济上也不划算——投入大、回报慢，财政负担重。"

<details>
<summary>展开答案</summary>

前提与结论：
1. 工程破坏湿地生态
2. 湿地破坏后难以恢复
3. 居民失去生计
4. 居民失业是严重社会问题
5. 工程投入大、回报慢
6. 工程造成财政负担重
7. 结论：应当反对工程

结构：
- (1)+(2) → 生态理由 → (7)
- (3)+(4) → 社会理由 → (7)
- (5)+(6) → 经济理由 → (7)

无明显重复前提；"投入大、回报慢"和"财政负担重"相关但可视为两个不同侧面，若严格合并也可算作一组经济理由。
