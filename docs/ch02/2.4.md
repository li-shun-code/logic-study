# 2.4 用推理题练手

> **这节课解决什么困惑**：论证分析练了不少，怎么检验自己真的会了？

## 推理题不是脑筋急转弯

原书第 2 章末尾给的是**推理问题**，不是数学题。它们考的是同一件事：你能不能从给定信息推出必然的结论，不添加、不脑补。

## 例题一：机组人员

> 某航班有机长、副驾驶、乘务长三人。已知：
> (1) 副驾驶比机长年轻；
> (2) 乘务长比机长年长；
> (3) 副驾驶不是最年长的。
>
> 三人按年龄从大到小怎么排？

**推导**：

- 由 (2)：乘务长 > 机长；
- 由 (1)：机长 > 副驾驶；
- 连起来：乘务长 > 机长 > 副驾驶。

(3) 是冗余信息——已经推出副驾驶最小，自然不是最年长。这告诉你：**推理中有些前提可能是多余的**，识别出来能省很多力。

## 例题二：四位艺术家

> 四位艺术家的作品展中，已知：
> - 画家的作品在雕塑家作品左边；
> - 雕塑家的作品在摄影家作品左边；
> - 摄影家的作品在雕刻家作品左边；
> - 雕刻家不是第一位。
>
> 作品顺序如何？

从"左边"关系直接串：画家 < 雕塑家 < 摄影家 < 雕刻家。四人的位置就定了。**雕刻家不是第一位**是冗余。

## 矩阵题怎么做

当信息是"谁和谁配对"（谁做什么、谁来自哪里）时，画一张表：

| | 画家 | 雕塑家 | 摄影家 | 雕刻家 |
| --- | --- | --- | --- | --- |
| 甲 | | | | |
| 乙 | | | | |

填一个"是"，同一行同一列的其他格子划"否"。随着条件增多，答案会浮现。这种题考的不是聪明，而是**系统化地把信息摆出来**——和论证图的思路完全一样。

## 三条做题纪律

1. **只用给定信息**。不要引入"一般说来"的背景知识。
2. **每一步都写下来**。脑内推理容易跳步，写下来才能检查。
3. **推出结论后回头验**：所有条件都满足了吗？

## 自测题

> 甲、乙、丙三人分别是医生、律师、教师。已知：
> (1) 甲不是医生；
> (2) 乙不是律师，也不是医生；
> (3) 丙不是教师。
>
> 三人各是什么职业？

<details>
<summary>展开答案</summary>

由 (2)：乙既不是律师也不是医生，所以乙是教师。
由 (3)：丙不是教师（已知乙是教师，一致）；由 (1)：甲不是医生。
剩下医生、律师给甲和丙。甲不是医生 → 甲是律师；丙是医生。

答案：甲=律师，乙=教师，丙=医生。
</details>
